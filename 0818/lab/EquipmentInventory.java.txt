=== 測試案例 ：正常流程與庫存不足 ===

輸入內容：
使用 main() 內建測試資料。

測試資料：
- E001 Camera，初始庫存 2
- E002 Mic，初始庫存 0
- Camera 執行 3 次借用
- Mic 執行 1 次借用
- Mic 歸還 3 件
- Mic 再執行 1 次借用

預期行為：
- Camera 前兩次借用成功。
- Camera 第三次借用失敗，庫存維持 0。
- Mic 初始庫存為 0，借用失敗。
- Mic 歸還 3 件後，庫存為 3。
- Mic 再借用一次後，庫存為 2。
- 整個測試流程中庫存不得小於 0。

實際輸出：
Borrow camera: true
Borrow camera: true
Borrow camera: false
Borrow mic: false
Borrow mic: true
E001 Camera available=0
E002 Mic available=2
